## Tasks

### T1: Implement `factcheck_agents/reranker.py`
**File**: `factcheck_agents/reranker.py` (create)  
**Description**: Node function `reranker(state: FactCheckState) -> dict`.

- **Pool**: `(state.get("evidence_real") or []) + (state.get("evidence_fake") or []) + (state.get("evidence_social") or [])`. If empty, return `{}` (D-05).
- **BM25 scoring** (RERANK-01): `from rank_bm25 import BM25Okapi`; corpus = `[e.get("snippet","").split() for e in pool]`; guard `if not corpus: return {}`. Scores normalized: `bm25_norm[i] = score[i] / (max(scores) or 1.0)` (D-02).
- **PhoBERT embedding scoring** (D-01): `from .agents.verify_agent import _phobert`; call `_phobert()` to get the cached singleton; encode claim and all snippets to CLS embeddings; compute cosine similarity. Catch all exceptions → BM25-only fallback (D-04).
- **Combine**: `final_score = 0.5 * bm25_norm + 0.5 * embed_cos_sim` (D-02). In BM25-fallback mode: `final_score = bm25_norm`.
- **Greedy fill** (D-03): iterate pool sorted by `final_score` descending; tokenize each snippet via PhoBERT tokenizer (or `len(snippet.split())` as fallback); add to `selected` while `total_tokens + next_tokens <= 256`. Always include the first item.
- **`consistency_score`** (D-06): mean cosine similarity of selected evidence embeddings to claim embedding. Set to `0.1` in BM25-fallback mode (D-07).
- **Return**: `{"evidence": selected, "consistency_score": consistency_score}` (D-05).
- **ImportError guard**: catch `ImportError` for rank_bm25 → return `{"evidence": pool, "consistency_score": 0.1}`.

Imports: `from .state import FactCheckState`, `from .config import settings`. No new deps beyond rank_bm25.  
**Acceptance test**: `uv run python -c "from factcheck_agents.reranker import reranker; s={'statement':'test','evidence_real':[{'snippet':'hello world','url':'http://x.com'}],'evidence_fake':[]}; r=reranker(s); assert 'evidence' in r and 'consistency_score' in r"`

## Threat model
- `rank_bm25` not installed: `ImportError` → catch, return full pool with `consistency_score=0.1`; log warning (pipeline never crashes)
- Empty snippet strings: BM25 tokenizes to `[]`; all BM25 scores 0; normalization guard `max(scores) or 1.0` prevents division by zero
- Single-item pool: max score = that score; normalization → 1.0; greedy fill always selects it
- PhoBERT checkpoint missing: `_phobert()` loads but `.encode()` raises → catch, BM25-only fallback, `consistency_score = 0.1`
- `evidence_real` and `evidence_fake` both empty after fan-out: reranker pool empty → returns `{}`; `route_nei_check` in graph handles NEI short-circuit (EVRET-04, implemented in Wave 3/4)
- Google Fact Check API call fails or returns malformed JSON: `requests.get` raises or `response.json()` raises → catch, stub to `[]`, continue
- Fan-out state merge: `real_source_agent` writes only `evidence_real`; `fake_source_agent` writes only `evidence_fake` — zero LangGraph field conflict
