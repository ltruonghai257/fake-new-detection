## Threat model
- Mocks must target `factcheck_agents.graph.<name>` (the name bound at import in `graph.py`), not `factcheck_agents.agents.real_source_agent.real_source_agent`; wrong namespace leaves real agent called
- `agreement_gate` runs real logic: mock verify output must have no `label=="NEI"` to avoid forced `agreement_score=0.0` and unexpected routing
- `reranker_node` import alias in `graph.py` (imported as `reranker_node` to avoid shadow): patch target must match the alias, e.g. `factcheck_agents.graph.reranker_node`
- `debate_node` runs real: `get_llm()` returns `None` in test env (no `OPENAI_API_KEY`); always returns `debate_exit_reason="no_llm"` and empty `debate_turns` — no JSONL file written; this is expected
- `social_loop_agent` is **not** in the 5 mocked agents; with mocked reranker returning `consistency_score=0.8` and evidence count=2, `route_social_loop` computes `cred=0.8 >= 0.6` → routes directly to `"verify"` — social_loop_agent never called; no mock needed
- `MemorySaver` is used (not `SqliteSaver`) to avoid SQLite file side effects in the test environment
- Each test uses a unique `thread_id` in the `config` dict to prevent state bleed between invocations
- Existing tests import from `factcheck_agents.agents` directly — adding new test file does not conflict with existing imports or fixtures
