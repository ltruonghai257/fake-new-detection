### T1: Implement `factcheck_agents/agents/social_loop_agent.py`
**File**: `factcheck_agents/agents/social_loop_agent.py` (create)  
**Description**: Node function `social_loop_agent(state: FactCheckState) -> dict`.

- Target domains: `["tiktok.com"] + [d.strip() for d in settings.flagged_domains.split(",") if d.strip()]` (D-08). Evaluated at call time (not hardcoded) so `FACTCHECK_FLAGGED_DOMAINS` is respected.
- Queries: `state.get("search_queries") or [state["statement"]]`.
- Per query: `web_search(q, max_results=settings.max_results, include_domains=targets)`; catch all exceptions → append to errors, `evidence_social = []`.
- Per result: dedup by URL (`seen: set`); `classify_domain(url)` for tier tagging; `_fetch_evidence_image(url)`.
- Always set `social_loop_fired = True` — even if search returns 0 results or raises (SOCLOOP-02).
- Write to `evidence_social` only — never merged into `evidence_real` or `evidence_fake` (D-09, EVRET-03).
- Return `{"evidence_social": results, "social_loop_fired": True, "messages": [("assistant", f"[SocialLoop] {len(results)} items")]}`.

Imports: same pattern as `social_search_agent.py`.

### T2: Implement `factcheck_agents/agents/agreement_gate.py`
**File**: `factcheck_agents/agents/agreement_gate.py` (create)  
**Description**: Two functions:

**(a) `agreement_gate(state: FactCheckState) -> dict`** — LangGraph node:
- Extract model confidences from `state.get("model_results", [])`:
  - Find PhoBERT result (`model == "phobert_vifactcheck"`); `ph_conf = result["confidence"] if result.get("available") else 0.0`.
  - Find COOLANT result; `co_conf = result["confidence"] if result.get("available") else 0.0`.
  - If **any available model** has `label == "NEI"` → force `agreement_score = 0.0` immediately (AGREE-01).
- Evidence credibility (AGREE-02): `cred = 0.40 * tier_score + 0.30 * count_score + 0.30 * consistency_score`
  - `evidence_real = state.get("evidence_real") or []`
  - `evidence_fake = state.get("evidence_fake") or []`
  - `tier_score = len([e for e in evidence_real if e.get("source_tier") == "trusted"]) / max(1, len(evidence_real))`
  - `count_score = min(1.0, (len(evidence_real) + len(evidence_fake)) / 5)`
  - `consistency_score = max(0.1, state.get("consistency_score", 0.1))` (D-07 floor)
- Agreement score, normalized over available signals (AGREE-01): collect weights `w_ph=0.30` if phobert available, `w_co=0.30` if coolant available, `w_ev=0.40` always; `agreement_score = (w_ph*ph_conf + w_co*co_conf + w_ev*cred) / (w_ph + w_co + w_ev)`.
- If `agreement_score >= settings.agreement_threshold`: write `{"debate_skipped": True, "request_id": state.get("request_id",""), "agreement_score": agreement_score, "timestamp": datetime.utcnow().isoformat()}` to `logs/debates/<request_id>.jsonl`; wrap in `try/except Exception: pass` (AGREE-03, DEBATE-03).
- Return `{"agreement_score": round(agreement_score, 4), "weight_breakdown": {"phobert": ph_conf, "coolant": co_conf, "evidence": round(cred, 4)}, "debate_exit_reason": "skipped_high_agreement" if agreement_score >= settings.agreement_threshold else ""}`.

**(b) `route_after_agreement(state: FactCheckState) -> str`** — routing function (no side effects):
- Returns `"judge"` if `state.get("agreement_score", 0.0) >= settings.agreement_threshold`, else `"debate"` (AGREE-03).

Directory creation: `Path("logs/debates").mkdir(parents=True, exist_ok=True)` at function call time (idempotent).  
**Acceptance test**: `uv run python -c "from factcheck_agents.agents.agreement_gate import agreement_gate, route_after_agreement; assert callable(agreement_gate) and callable(route_after_agreement)"`

### T3: Add routing helpers to `factcheck_agents/graph.py`
**File**: `factcheck_agents/graph.py` (modify)  
**Description**: Add two module-level routing functions after `route_after_verify`. These are used by `build_debate_graph()` in Wave 4. Do NOT modify `build_graph()` or any existing code.

```python
def route_nei_check(state: FactCheckState) -> str:
    """EVRET-04: NEI short-circuit when both evidence lists are empty after fan-out."""
    real = state.get("evidence_real") or []
    fake = state.get("evidence_fake") or []
    return "judge" if not real and not fake else "reranker"


def route_social_loop(state: FactCheckState) -> str:
    """SOCLOOP-01/02/03: fire social loop at most once, only when evidence is weak."""
    real = state.get("evidence_real") or []
    fake = state.get("evidence_fake") or []
    count = len(real) + len(fake)
    cred = state.get("consistency_score", 0.1)
    if (
        not state.get("social_loop_fired", False)
        and count < settings.social_loop_min_count
        and cred < settings.social_loop_min_credibility
    ):
        return "social_loop"
    return "verify"
```

## Threat model
- `social_loop_fired=True` on input: `route_social_loop` short-circuits before any `web_search` call (SOCLOOP-03)
- Social search raises exception: catch per-query; `evidence_social=[]`; `social_loop_fired=True` still set; pipeline continues
- `consistency_score` absent from state when agreement_gate runs: `max(0.1, state.get("consistency_score", 0.1))` guarantees AGREE-02 floor
- All models unavailable: both confidences = 0.0; `agreement_score = 0.40 × cred`; with default threshold 0.7 this almost always routes to debate — intended behavior
- NEI label from any model: `agreement_score = 0.0` immediately → always routes to debate (prevents false-positive bypass)
- `logs/debates/` write failure (disk full, permissions): wrapped in `try/except Exception: pass`; pipeline is not blocked
- `route_nei_check` with non-empty `evidence_real`: returns `"reranker"` — correctly skips NEI path
- `route_social_loop` with `consistency_score >= social_loop_min_credibility` (0.6): returns `"verify"` regardless of count — prevents unnecessary social search when evidence quality is sufficient
