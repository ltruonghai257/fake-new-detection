### T1: Implement `factcheck_agents/agents/debate_node.py`
**File**: `factcheck_agents/agents/debate_node.py` (create)  
**Description**: Node function `debate_node(state: FactCheckState) -> dict`.

- **No-LLM guard**: if `get_llm() is None`, return `{"debate_turns": [], "debate_exit_reason": "no_llm", "messages": [("assistant", "[Debate] skipped — no LLM configured")]}` immediately (DEBATE-02).
- **Dir creation**: `Path("logs/debates").mkdir(parents=True, exist_ok=True)` at function entry.
- **Loop** `for round_num in range(settings.max_debate_rounds)` (DEBATE-02, D-15):
  - Build `real_advocate` user prompt: claim text + `evidence_real` snippets tagged `[TRUSTED]`/`[FLAGGED]`/etc. + last `fake_advocate` turn if `round_num > 0` (DEBATE-01).
  - Call `llm.invoke([("system", REAL_ADVOCATE_PROMPT), ("user", user_text)])`. On exception: append error turn `{"agent": "real_advocate", "round": round_num, "timestamp": ..., "text": "", "error": str(exc)}`; set `exit_reason = "llm_error"`; `break`.
  - Build `fake_advocate` user prompt: claim + `evidence_fake` snippets + last `real_advocate` turn (DEBATE-01).
  - Call LLM for `fake_advocate`; same error handling.
  - Per turn: append dict `{"agent": "real_advocate"|"fake_advocate", "round": round_num, "timestamp": datetime.utcnow().isoformat(), "text": str(response.content)}` to `turns` list; `print(turn)` to stdout; call `_append_turn(request_id, turn)` (DEBATE-03).
- **`_append_turn(request_id, turn)`** helper: `open(Path("logs/debates") / f"{request_id}.jsonl", "a", encoding="utf-8")` + `json.dumps(turn, ensure_ascii=False) + "\n"`; wrapped in `try/except Exception: pass` (DEBATE-03).
- Return `{"debate_turns": turns, "debate_exit_reason": exit_reason or "max_rounds", "messages": [...]}`.

Prompts: define `REAL_ADVOCATE_PROMPT` and `FAKE_ADVOCATE_PROMPT` as module-level string constants. Real advocate must cite `evidence_real` only; fake advocate must cite `evidence_fake` only (DEBATE-01).  
**Acceptance test**: `uv run python -c "from factcheck_agents.agents.debate_node import debate_node, _append_turn; print('ok')"`

### T2: Implement `factcheck_agents/agents/judge_agent.py`
**File**: `factcheck_agents/agents/judge_agent.py` (create)  
**Description**: Node function `judge_agent(state: FactCheckState) -> dict`. Mimic `conclusion_agent.py` skeleton.

- **NEI short-circuit** (EVRET-04): if `not (state.get("evidence_real") or []) and not (state.get("evidence_fake") or [])`: return `{"verdict": Verdict(label="NEI", verdict_binary="FAKE", verdict_label_vi="Giả", confidence=0.1, rationale="No evidence retrieved from either source.", citations=[]), "weight_breakdown": {}, "messages": [("assistant", "[Judge] NEI — no evidence")]}`. No LLM call.
- **Dir creation**: `Path("logs/verdicts").mkdir(parents=True, exist_ok=True)`.
- **Fallback** if `get_llm() is None`: call `_fallback_verdict(model_results, evidence)` — copy the function verbatim from `conclusion_agent.py`.
- **LLM path**: build user prompt from claim, model_results (formatted), evidence_real + evidence_fake snippets, and `debate_turns` (if any). Request: score each turn on 3 dimensions 1–5 (Factuality, Rebuttal Engagement, Evidence Grounding) and produce final verdict JSON (JUDGE-01).
- **Weight computation** (JUDGE-02): extract `ph_conf` and `co_conf` from model_results; `ev_cred = state.get("weight_breakdown", {}).get("evidence", 0.1)`; `confidence = ph_conf*0.30 + co_conf*0.30 + ev_cred*0.40`. If `not state.get("debate_turns")`: `confidence = min(confidence, 0.7)` (JUDGE-02 cap).
- **Verdict construction**: parse LLM JSON response; build `Verdict` TypedDict; on parse failure fall through to `_fallback_verdict` with `rationale += f" (LLM error: {exc})"` (pattern from `conclusion_agent.py` line 168–169).
- **Log write** (JUDGE-03): `_write_verdict_log(request_id, {"verdict": verdict, "weight_breakdown": weight_breakdown, ...})`; wrapped in `try/except Exception: pass`.
- Return `{"verdict": verdict, "weight_breakdown": {"phobert": ph_conf, "coolant": co_conf, "evidence": ev_cred, "argument_scores": turn_scores}, "messages": [...]}`.

Helper `_write_verdict_log(request_id, data)`: `open(Path("logs/verdicts") / f"{request_id}.json", "w", encoding="utf-8")` + `json.dump(data, f, ensure_ascii=False, indent=2)`.  
**Acceptance test**: `uv run python -c "from factcheck_agents.agents.judge_agent import judge_agent, _write_verdict_log; print('ok')"`

**Full topology** (D-12 static fan-out, no Send API):
```python
def build_debate_graph(checkpointer=None):
    from langgraph.checkpoint.memory import MemorySaver
    if checkpointer is None:
        checkpointer = MemorySaver()

    g = StateGraph(FactCheckState)
    g.add_node("real_source", real_source_agent)
    g.add_node("fake_source", fake_source_agent)
    g.add_node("nei_gate", lambda state: {})      # barrier; routing via conditional edge
    g.add_node("reranker", reranker_node)
    g.add_node("social_loop", social_loop_agent)
    g.add_node("verify", verify_agent)
    g.add_node("agreement_gate", agreement_gate)
    g.add_node("debate", debate_node)
    g.add_node("judge", judge_agent)

    g.add_edge(START, "real_source")              # D-12: static fan-out
    g.add_edge(START, "fake_source")
    g.add_edge("real_source", "nei_gate")         # implicit barrier merge
    g.add_edge("fake_source", "nei_gate")
    g.add_conditional_edges("nei_gate", route_nei_check,
                            {"reranker": "reranker", "judge": "judge"})
    g.add_conditional_edges("reranker", route_social_loop,
                            {"social_loop": "social_loop", "verify": "verify"})
    g.add_edge("social_loop", "verify")
    g.add_edge("verify", "agreement_gate")
    g.add_conditional_edges("agreement_gate", route_after_agreement,
                            {"debate": "debate", "judge": "judge"})
    g.add_edge("debate", "judge")
    g.add_edge("judge", END)
    return g.compile(checkpointer=checkpointer)
```

## Threat model
- `get_llm() is None` in `debate_node`: returns empty turns + `"no_llm"` exit reason; pipeline flows to `judge` normally
- LLM raises mid-round: catch exception, append error turn, set `"llm_error"` exit reason, `break`; partial turns preserved in state
- `logs/debates/` or `logs/verdicts/` write fails: all `_append_turn` / `_write_verdict_log` calls wrapped in `try/except Exception: pass`; pipeline never blocked
- NEI short-circuit: `nei_gate` routes to `"judge"` when both evidence lists are empty; `judge_agent` detects empty evidence and returns fixed NEI verdict without LLM call (EVRET-04)
- `debate_node` runs with empty `evidence_real` or `evidence_fake`: advocate prompt includes `"(no supporting evidence available)"`; still produces text from claim alone (DEBATE-01)
- `build_graph()` unchanged: the only additions to `graph.py` are imports and the new function; no existing symbol modified
- LangGraph fan-out barrier: both `real_source` and `fake_source` must complete before `nei_gate` executes — guaranteed by LangGraph's implicit join when multiple edges lead to the same node (D-12)
- Import of M2 agents at graph.py module level does not cause circular imports: none of the new agent files import from `graph.py`
