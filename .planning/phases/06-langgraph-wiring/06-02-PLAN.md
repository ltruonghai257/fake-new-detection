<threat_model>

## Trust Boundaries

| Boundary                         | Description                                                    |
| -------------------------------- | -------------------------------------------------------------- |
| env var → settings.checkpoint_db | File path comes from env; used as SQLite DB path, not executed |
| SqliteSaver DB file              | Checkpoint state written to disk; contains pipeline state data |

## STRIDE Threat Register

| Threat ID | Category               | Component                                         | Disposition | Mitigation Plan                                                                                                                |
| --------- | ---------------------- | ------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------ |
| T-06-03   | Tampering              | FACTCHECK_CHECKPOINT_DB env path                  | accept      | path is used for checkpoint read/write only, not executed as code; no path traversal risk beyond normal filesystem permissions |
| T-06-04   | Information Disclosure | .factcheck_checkpoints.db contains pipeline state | mitigate    | add to .gitignore so checkpoint DB is never committed; file stays local                                                        |
| T-06-05   | Denial of Service      | SqliteSaver write on interrupted run              | accept      | LangGraph's SqliteSaver is designed for this use case; concurrent writes go through SQLite's WAL mode                          |
| T-06-SC   | Tampering              | langgraph[sqlite] package import                  | accept      | langgraph is an existing project dependency; ImportError fallback prevents breakage if extra is missing                        |

</threat_model>
