-   `.planning/phases/04-langgraph-a2a-client-wiring/04-CONTEXT.md` — D-05 (partial debate: mark side down, skip turns, convergence check skipped for one-sided, both down → exit_reason="agent_unavailable")
    </read_first>

<action>
Refactor the `debate_node` function body in `factcheck_agents/graph.py`. The function signature, docstring, and return dict structure stay the same. Changes inside the function:

1. **Add import at top of function**: `from .a2a_client import AgentUnavailableError` (or import at module level alongside other a2a_client imports)

2. **Add two boolean flags before the loop**: `real_down = False`, `fake_down = False`

3. **Replace `real_advocate({...})` call** (currently `real_out = real_advocate({**state, "debate_turns": turns, "debate_role": "real"})`) with:

    - Wrap in `try/except AgentUnavailableError`
    - On exception: set `real_down = True`, `logger.warning(...)`, `continue` to next round iteration (skip this round for both sides since real failed first)
    - On success: proceed as before — `real_turn = real_out["debate_turn"]`

4. **Replace `fake_advocate({...})` call** similarly:

    - Wrap in `try/except AgentUnavailableError`
    - On exception: set `fake_down = True`, `logger.warning(...)`, handle based on state

5. **Add partial-debate skip logic**:

    - If `real_down and fake_down`: set `exit_reason = "agent_unavailable"`, `break`
    - If `real_down`: skip `real_advocate` call, only run `fake_advocate` this round; still append `{"agent": "real_advocate", "error": "agent_unavailable"}` to turns for the missing side
    - If `fake_down`: skip `fake_advocate` call, only run `real_advocate` this round; still append error turn for missing side

6. **Update convergence check**: Only run `if real_v == fake_v and real_v in {"REAL", "FAKE"}` when BOTH advocates are available (not down). If one-sided, skip convergence check.

7. **Fix IN-07**: Move `turns.append(real_turn)` and `turns.append(fake_turn)` after their respective None checks — only append non-None turns from available advocates. Error turns from unavailable sides are always appended.

8. **Keep the rest unchanged**: `llm = get_llm()` check, `Path("logs/debates").mkdir(...)`, return dict structure.
   </action>
