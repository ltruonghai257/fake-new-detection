# 04-01: Implement `a2a_client.py`

## Goal

Create `factcheck_agents/a2a_client.py` with `AgentUnavailableError`, a base `call_agent()` using `httpx.Client` (sync, per D-01), a `@degrade_on_unavailable` decorator, 10 typed wrapper functions (one per A2A agent), and the EvidenceGraph rebuild logic (D-03). Add A2A client timeout configuration to `config.py`.

## must_haves

-   `factcheck_agents/a2a_client.py` exists with all 10 typed wrappers
-   Each wrapper constructs a valid `SendMessageRequest`, calls `POST http://localhost:{port}/message:send` via `httpx.Client`, and returns a deserialized `dict`
-   `AgentUnavailableError` is raised on `httpx.HTTPError` or `TASK_STATE_FAILED`
-   `@degrade_on_unavailable` decorator catches `AgentUnavailableError` and returns a per-agent degrade diff
-   `search_agent` wrapper rebuilds `EvidenceGraph` locally from the returned `evidence` list (D-03)
-   `config.py` `Settings` gains `a2a_client_timeout` and per-agent `a2a_client_timeout_<NAME>` fields
-   All 10 wrappers are importable as `from factcheck_agents.a2a_client import <name>`

    - `__init__(self, agent_name: str = "", port: int = 0, cause: str = "")`
    - Stores `self.agent_name`, `self.port`, `self.cause`
    - `super().__init__(f"[{agent_name}:{port}] unavailable: {cause}")`

5. **`_timeout_for(agent_name: str) -> float`**:

    - If `settings.a2a_client_timeout` is set (not None), return it as float
    - Otherwise look up the per-agent Settings field by mapping the agent name to the field suffix (e.g., `"search_agent"` → `"search"`, `"agreement_gate"` → `"agreement_gate"`), then read `getattr(settings, f"a2a_client_timeout_{suffix}")` — which always has a hardcoded default from Task 04-01-01 (120, 60, or 30)
    - No module-level fallback dict needed; Settings defaults are the single source of truth

6. **`call_agent(agent_name: str, state: FactCheckState) -> dict`**:

    - `port = a2a_ports()[agent_name]`
    - `timeout = _timeout_for(agent_name)`
    - `payload = serialize_state(dict(state))`
    - Build `request_body = {"message": {"role": "user", "parts": [{"data": payload}], "messageId": f"msg-{uuid.uuid4()}"}}`
    - `try:` POST to `f"http://localhost:{port}/message:send"` with `httpx.Client(timeout=timeout)`, `resp.raise_for_status()`
    - `except httpx.HTTPError as exc:` raise `AgentUnavailableError(agent_name, port, str(exc))`
    - Parse `task = resp.json()`, get `task_state = task.get("status", {}).get("state", "")`, `artifacts = task.get("artifacts", [])`
    - If `task_state == "TASK_STATE_FAILED"`: extract error from artifact, raise `AgentUnavailableError(agent_name, port, error_data.get("error", "server error"))`
    - If `task_state == "TASK_STATE_WORKING"` (Risk 2 mitigation): log warning, return `{}`
    - Otherwise (COMPLETED): return `_extract_artifact_data(artifacts)`

7. **`_extract_artifact_data(artifacts: list) -> dict`**:
    - Iterate artifacts; for artifact with `name == "output"`, return `parts[0]["data"]` if it exists
    - Return `{}` if no output artifact found
      </action>
