# Plan 05-01: SSE stage_error Bridge Update

## Goal

Insert the `stage_error` detection block into `demo_app/backend/streaming.py`'s `run_graph()` function so that when any A2A agent is unreachable and injects an `"unavailable"` message into the state diff, the SSE stream emits a Vietnamese-language `stage_error` event and closes gracefully with HTTP 200.

---

<threat_model>
| ID | Threat | Severity | Mitigation | Status |
|----|--------|----------|------------|--------|
| T-01 | SSE `stage_error` event exposes dynamic error strings (stack traces, agent names, internal port numbers) to the browser client — information disclosure | MED | Use only the fixed Vietnamese message string `"Một số dịch vụ tạm thời không khả dụng. Không thể hoàn thành phân tích."` in `data.message`; no dynamic fields from `exc` or node output included in stage_error payload | MITIGATED |
| T-02 | Race between `done.set()` + `break` in stage_error path and the outer `except Exception as exc` block — risk of double `_done` event or HTTP 500 leaking through | MED | `done.set()` followed by `break` exits the `for` loop cleanly; the `except` block only fires if an unhandled exception propagates out of the loop body — the stage_error path does NOT raise; `finally` always calls `done.set()` (asyncio.Event.set is idempotent) | MITIGATED |
| T-03 | `done.set()` called with argument (e.g. `done.set(True)`) instead of `done.set()` — `asyncio.Event.set()` takes no arguments; passing one raises `TypeError` at runtime | LOW | Action specifies exact call `done.set()` with no arguments; acceptance criterion asserts the exact string `done.set()` (no argument) appears in the inserted block | MITIGATED |
| T-04 | New check inserted at the wrong location (after the stage_start emission) causes stage_start to fire before the error is detected — frontend shows a false stage progress update before closing | LOW | Insert point is explicitly after `accumulated.update(node_output)` and before `stage = NODE_STAGE_MAP.get(node_name)` per PATTERNS.md §1; acceptance criterion asserts relative order via grep context | MITIGATED |
</threat_model>

```python
                messages = node_output.get("messages", [])
                if any(
                    "unavailable" in str(part)
                    for msg in messages
                    for part in (msg if isinstance(msg, (list, tuple)) else [msg])
                ):
                    _post({"type": "stage_error", "data": {"message": "Một số dịch vụ tạm thời không khả dụng. Không thể hoàn thành phân tích."}})
                    done.set()
                    break
```

- Do NOT add any imports (no new imports needed for this task)
- Indentation must match the surrounding code (spaces, not tabs)

</action>
