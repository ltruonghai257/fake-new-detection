<threat_model>
| ID | Threat | Severity | Mitigation | Status |
|----|--------|----------|------------|--------|
| T-01 | Integration tests start real uvicorn servers on fixed ports 9001–9010 — port collision with a running `start_agents.sh` instance binds fail and block the test session | HIGH | Apply `socket.connect_ex(("127.0.0.1", port))` guard at the start of each test and the session fixture; call `pytest.skip()` (not `pytest.fail()`) when port is already occupied; use `daemon=True` threads so servers die with the pytest session even on crash | MITIGATED |
| T-02 | `OPENAI_API_KEY` / `TAVILY_API_KEY` printed to stdout/stderr on integration test failure — API key exposure in CI logs | HIGH | All new tests in `test_agent_http.py` and `test_a2a_integration.py` marked `@pytest.mark.integration`; excluded from default `pytest tests/ -m "not integration"` run; CI must pass `--no-header -p no:logging` or equivalent to suppress key leakage; test assertions must NOT print environment variable values | MITIGATED |
| T-03 | `thread_id` not set in `run_fact_check()` and `mcp_server.py` — MemorySaver checkpointer reuses thread `None` across concurrent calls, causing state bleed between sessions | MED | Fix generates `str(uuid.uuid4())` per invocation in both `factcheck_agents/__init__.py` and `factcheck_agents/mcp_server.py`; each call gets a unique thread_id that cannot collide | MITIGATED |
| T-04 | uvicorn server threads from session fixture not shut down between test runs — leaked ports across multiple pytest invocations in the same terminal session | MED | `daemon=True` guarantees cleanup on process exit; session fixture sets `server.should_exit = True` in its teardown block; `thread.join(timeout=5)` after should_exit | MITIGATED |
| T-05 | Integration test sends real HTTP requests to 127.0.0.1 agents — if a test crashes mid-run, the server thread may hold the port open for the OS default socket timeout | LOW | `daemon=True` thread dies with the process; socket reuse is a kernel concern, not addressable at test level; port-conflict skip guard at test start handles the reuse window | MITIGATED |
</threat_model>

```python
    finally:
        server.should_exit = True
```

```python
@pytest.fixture(scope="session")
def a2a_agent_servers():
    """Start 8 graph-path A2A agents (ports 9003–9010) for the test session."""
    ports = a2a_ports()
    agents_to_start = [
        (RealSourceAgentHandler, ports["real_source_agent"]),   # 9003
        (FakeSourceAgentHandler, ports["fake_source_agent"]),   # 9004
        (SocialLoopAgentHandler, ports["social_loop_agent"]),   # 9005
        (AgreementGateHandler,   ports["agreement_gate"]),      # 9006
        (RealAdvocateHandler,    ports["real_advocate"]),       # 9007
        (FakeAdvocateHandler,    ports["fake_advocate"]),       # 9008
        (JudgeAgentHandler,      ports["judge_agent"]),         # 9009
        (ConclusionAgentHandler, ports["conclusion_agent"]),    # 9010
    ]
    servers = []
    for handler_cls, port in agents_to_start:
        s = socket.socket()
        result = s.connect_ex(("127.0.0.1", port))
        s.close()
        if result == 0:
            pytest.skip(f"Port {port} already in use — cannot start session fixture")
        app = create_app(handler_cls(), handler_cls.agent_card_config)
        cfg = uvicorn.Config(app, host="127.0.0.1", port=port, log_level="warning")
        server = uvicorn.Server(cfg)
        thread = threading.Thread(target=server.run, daemon=True)
        thread.start()
        # Poll readiness up to 10 s
        deadline = time.time() + 10
        ready = False
        while time.time() < deadline:
            try:
                r = httpx.get(f"http://127.0.0.1:{port}/.well-known/agent.json", timeout=1)
                if r.status_code == 200:
                    ready = True
                    break
            except Exception:
                time.sleep(0.1)
        if not ready:
            pytest.fail(f"Agent on port {port} did not become ready within 10 s")
        servers.append(server)
    yield
    for server in servers:
        server.should_exit = True
```
