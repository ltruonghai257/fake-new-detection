# Plan 05.1-01: PhoBERT/COOLANT toggles, COOLANT+evidence default, and prompt hooks

## Goal

Wire the existing `FactCheckState` ablation toggles (`use_phobert`, `use_coolant`, `use_evidence`) through `Settings`, `initial_state()`, and `evaluate_agent.py`. Make the real/fake advocate and judge prompts build from whichever models are actually available, with the default being COOLANT + evidence. Add `judge_prompt` and `conclusion_prompt` override hooks in `Settings` so prompts can be customized later without code changes. Ensure all A2A agents still start and the existing non-integration test suite stays green.

---

<threat_model>
| ID | Threat | Severity | Mitigation | Status |
|----|--------|----------|------------|--------|
| T-01 | Custom prompt overrides (`judge_prompt`/`conclusion_prompt`) can contain instructions that conflict with the required JSON output schema or leak system context | MED | Prompt override is opt-in via env var; default prompts remain vetted; acceptance criteria assert that overridden prompts still produce parseable JSON | MITIGATED |
| T-02 | Disabling a model with `use_phobert=False` but leaving `agreement_threshold` too high could cause `agreement_gate` to skip debate and produce a verdict with only evidence/COOLANT | LOW | `agreement_gate` already normalizes weights over available signals; tests must verify a verdict is produced with `use_phobert=False` | MITIGATED |
| T-03 | A2A `evaluate_agent` HTTP test may fail if `VIFACTCHECK_CKPT_DIR` is unset, blocking unrelated changes | LOW | Existing `test_agent_http.py` already skips `evaluate_agent` when `VIFACTCHECK_CKPT_DIR` is missing; keep that guard and do not remove it | MITIGATED |
| T-04 | `initial_state()` default change could break external callers or tests expecting `use_phobert=True` | MED | Add the new defaults in `initial_state()` but keep the function signature unchanged; tests in `test_evaluate_agent.py` / `test_debate_pipeline_integration.py` must be reviewed and updated if they assert old defaults | MITIGATED |
</threat_model>
