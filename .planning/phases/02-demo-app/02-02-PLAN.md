### T2: Implement `demo_app/frontend/src/App.tsx`
**File**: `demo_app/frontend/src/App.tsx` (create)  
**Description**: Main application component. Manages all SSE state and orchestrates UI components. All user-visible strings in Vietnamese (DEMO-04).

Key implementation requirements:
1. **TypeScript interfaces** — define `Verdict`, `WeightBreakdown`, `ArgumentScore`, `Evidence`, `DebateTurn` matching `02-RESEARCH.md §5` SSE event shapes
2. **Stage constants** — `STAGES` array and `STAGE_LABELS` record per D-10
3. **`useAnalysis()` hook (or inline)** — manages EventSource lifecycle:
   - Creates EventSource on `requestId` change: `new EventSource(\`http://localhost:8000/api/stream/${requestId}\`)`
   - `return () => es.close()` in useEffect (StrictMode cleanup, DEMO-04)
   - Handles: `stage_start` → update `currentStage`, append to `completedStages`; `turn_start` → reset `currentTurnText`; `chunk` → append to `currentTurnText`; `turn_end` → push completed turn to `allTurns`; `verdict` → setVerdict, setWeightBreakdown, setEvidenceReal, setEvidenceFake, setShowEvidence(true), setShowBadges(true) (D-05, D-07); `error` → setIsError(true), es.close()
4. **Submit handler** — `POST /api/analyze` via `fetch` with `FormData` containing `statement`, optional `image_url`, optional `image_file`; receives `{request_id}`; sets `requestId` state
5. **Error state** — when `isError`, show red card "Đã xảy ra lỗi. Vui lòng thử lại." with "Thử lại" button that resets state (D-11)
6. **Layout** — `<StageIndicator>`, `<DebateTranscript>`, `<VerdictCard>` + `<EvidencePanel>` (only shown when `showEvidence`)
7. **Form fields** — textarea for statement (label "Nhập câu cần kiểm tra"), URL input (label "URL hình ảnh"), file input (label "Hoặc chọn tệp hình ảnh"), submit button "Kiểm tra"

## Threat model
- **React StrictMode double-connect:** EventSource created in `useEffect` with cleanup `return () => es.close()` — StrictMode mounts twice but closes before second mount (DEMO-04).
- **Current turn text state after `turn_end`:** App resets `currentTurnText` on `turn_start` and freezes completed turns; no leaked state between turns.
- **Score badges referencing wrong turn:** `argument_scores.find(s => s.agent === turn.agent && s.round === turn.round)` — unique per agent+round; returns `undefined` safely handled.
- **Large `debate_turns` in `verdict` event + re-render:** Final `verdict` event carries all turns with scores; single state update (multiple `set*()` calls batched by React 18 automatic batching).
- **D-04 both image sources:** URL takes priority — `image_url` form field is checked first; file is only sent to backend when URL is empty.
- **CORS for FormData POST:** `CORSMiddleware` in backend allows `*` methods and headers for `localhost:5173` — OPTIONS preflight passes.
- **TypeScript strict mode `noUnusedLocals`:** All imported types and variables must be used; unused state should not be declared.
- **Download link opens new tab instead of downloading:** `download` attribute on `<a>` triggers download; same-origin restriction relaxed since `FileResponse` sets `Content-Disposition: attachment`.
