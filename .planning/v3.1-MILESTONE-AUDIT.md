## Tech Debt Summary

See `tech_debt` frontmatter — 10 items across 3 phases. Highlights:

1. **Latent serialization risk:** `conclusion_agent` only handles `EvidenceGraph` as repr string; a `_asdict` dict payload would not rebuild. Also `LANGGRAPH_STRICT_MSGPACK=true` would block the unregistered type. Consider a follow-up hardening task.
2. **Fixture coverage gap:** `test_a2a_integration.py` doesn't cover the `build_graph` (M1) path — `search_agent` absent from fixture.
3. **Port conflicts:** default 9001–9009 collide with user's Jupyter kernels; rely on `A2A_PORT_*` overrides.
4. **Pre-existing test drift:** 5 label-mapping failures pre-dating v3.1 were fixed in Phase 05 (159 green); integration tests still marked `@pytest.mark.integration` (excluded by default, need live servers).

## Conclusion

Milestone v3.1 achieved its definition of done: all 10 agents run as A2A HTTP services with Agent Cards, LangGraph nodes call them via `a2a_client`, graceful degradation works end-to-end (proven live both directions), the demo app bridges stage errors over SSE, and external interfaces (CLI / `run_fact_check()` / MCP) are unchanged. No critical gaps. Tech debt items are documented for the backlog.
